# 《时间的尽头》两个独立版本

| 作品入口 | 制作工具与模型 | 主要交互 |
| --- | --- | --- |
| `experiences/end-of-time/index.html` | **Claude Code opus5.5** | 接近或坠入黑洞，观察时间膨胀与宇宙纪元，投入「瞬间」 |
| `experiences/end-of-time-sol/index.html` | **Codex 6.1 sol** | 环绕破碎天文钟，暂停或倒流时间，释放引力脉冲，收集三枚记忆 |

制作归属按用户提供的信息记录。两件作品保留各自独立的场景、源码、封面与路由。卡片的中英文副标题直接注明制作工具与模型；`content/works.json` 的 `production` 字段另保存结构化记录。作者署名仍为观默 / @guanmo_ai。

## 本次接入

新增 SOL 版，没有覆盖前一版的场景。沿用仓库固定的 Three.js 0.186.1 和 Vite 8.3.5；保留原作的构图、材质、音效、时间控制和记忆交互。

- 加入返回图鉴的相对导航与 `body.ready` / `body.has-error` 状态。
- 复用源作品现有的双语字典，共享 `three-atlas.language` 偏好。
- 字体随作品打包，资源地址兼容图鉴的项目子路径。
- 使用实际 WebGL 场景的 2880×1800 原生截图作为封面，自动生成 720 / 1440 / 2880 的 AVIF、WebP 和环境光图，没有放大低清截图。
- 实测发现顶部栏的空白区域会挡住第三枚晶体；将鼠标命中限定在顶部链接和按钮后，三枚晶体均可拾取，英文结语可达。
