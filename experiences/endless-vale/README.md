# ENDLESS VALE / 无尽之谷

沿着一条河一直往前飞。山谷在前方实时生成，金色草甸、粉雾花坡、赤岩台地、霜白高原轮流出现，天色从黄昏走到深夜，再到清晨。

- 入口：`/experiences/endless-vale/index.html`，左上角返回 Three Atlas。
- 滚动或上下滑动调整速度（向上滚可以减速、倒退），松开后回到巡航；拖动环顾；方向键或 WASD 也能飞。
- 空格暂停或继续，H 纯享，T 切换时间；底部可以选择「流转 / 清晨 / 白昼 / 黄昏 / 夜晚」。
- 中英文与图鉴共用语言偏好。系统开启减少动态效果时默认暂停，不做视角倾斜和视野变化；滚动可以慢慢前进。

## 怎么做的

- **世界是坐标的函数**：`src/world.js` 用确定性的 simplex 噪声描述河道曲线、山谷剖面、山脊和四种地貌的过渡；`src/scatter.js` 按全局网格放置树、岩石、晶簇、立石、村舍、石灯、浮空岛和跨河石门。往回飞看到的还是同一片山谷。
- **四叉树地形**：近处 64 m 地块、远处最大 512 m，每块 48×48 网格（触屏 32×32）加裙边（`src/land.js`、`src/tiles.js`）。旧地块在新地块就绪前保留，不会出现空洞。
- **后台线程**：地形、物件和草丛在 Web Worker 中生成（`src/worker.js`），浏览器不支持时退回主线程分片执行。
- **实例化与分级**：每类物件用一个 InstancedMesh；210 m 内用完整模型并投射阴影，远处换成低面数模型。
- **光与大气**：天空、远景雾和河面共用同一套大气着色（`src/atmosphere.js`），远山会融进地平线。太阳和月亮的方向、颜色按时刻插值（`src/time.js`）。
- **河面**：平面反射实时映出两岸，叠加多层细波、太阳闪光与岸边泡沫（`src/water.js`）。
- **后期**：多重采样场景 → 半分辨率太阳光束 → 辉光 → 调色、暗角与 ACES 色调映射（`src/post.js`）。
- **生命感**：草丛随阵风起伏，树冠逆光透亮，白天有花粉与鸟群，夜里有萤火、石灯、村舍窗光和缓缓升起的天灯。

画质分两档：桌面使用河面反射、太阳光束、2048 阴影和更远的视距；触屏或小屏使用更轻的设置。帧时间持续超预算时自动降低像素比。
