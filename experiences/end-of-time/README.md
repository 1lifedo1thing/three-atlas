# THE END OF TIME / 时间的尽头

一个可以坠入的黑洞，也是一座宇宙时钟的轴心。表盘、指针和散落的黄铜齿轮都绕着它转。越靠近视界，你的一秒越长，外面的宇宙老得越快：恒星熄灭，质子衰变，齿轮化成灰，最后只剩黑洞和仍在走动的时钟。越过视界，下一个宇宙从白光里开始。

- 入口：`/experiences/end-of-time/index.html`，左上角返回 Three Atlas。
- 拖动或方向键环视；滚轮、双指张合或 W / S 靠近、远离视界；点击投入一个「瞬间」。
- 空格让时间静止（视角仍可转动），F 自动坠入视界，C 随机投入一个瞬间，M 开关声音。到最内侧后继续向内，就会越过视界。
- 中英文与图鉴共用语言偏好。系统开启减少动态效果时，打开即是时间静止状态，不自动环绕、不做视差。

制作过程与踩过的坑见 [MAKING.md](./MAKING.md)，可复用的经验已整理到 [docs/lessons.md](../../docs/lessons.md)。

## 怎么做的

单位取史瓦西半径 r<sub>s</sub> = 1。

- **黑洞是逐像素追踪出来的**（`src/shaders.js` 的 `BH_FRAG`）：每个像素沿史瓦西度规积分一条光线，`x'' = −1.5 h² x / r⁵`，步长随半径缩放，最多 320 步；远离黑洞的光线用解析的弱场偏折收尾。吸积盘从最内稳定轨道 3 r<sub>s</sub> 开始，温度按 Novikov–Thorne 曲线分布，再乘多普勒因子与引力红移，所以迎面一侧更亮更蓝。光子环由守恒的碰撞参数 b 在临界值 3√3/2 附近给出。这一层单独渲染到较低分辨率的半浮点目标，是画质自适应的主要旋钮。
- **其他物体也被引力弯曲**（`LENS`）：表盘线条、罗马数字、铭文环、指针、时之砂和「瞬间」都在顶点着色器里按点透镜公式 `θ = (β + √(β² + 4θ_E²)) / 2` 移到它们的像所在的位置。实心齿轮被拉成爱因斯坦弧时会撕裂，所以改为隐去（`src/gears.js`）。
- **时钟**（`src/clock.js`）：所有线条是屏幕空间扩展的四边形，至少 1.3 像素宽并带抗锯齿，两端分别做透镜。指针的转速由外部时钟倍率决定，转快后身后拖出扇形残影。
- **时之砂**（`src/dust.js`）：桌面 14 万粒、触屏 6 万粒，沿开普勒螺旋落入，半径随相位线性减小，轨道角有闭式积分，CPU 每帧不做任何粒子计算。旋臂是固定的密度波，颗粒穿行其中。
- **时间与纪元**（`src/physics.js`）：读数里的 `dτ/dt = √(1 − r_s/r)` 是静止观察者的真实值；外部时钟倍率与宇宙年龄的增长速度由它放大而来。纪元按 Adams & Laughlin 划分：蓝色恒星先熄灭（熄灭前闪一下），红矮星最后熄灭，10³⁰–10⁴¹ 年质子衰变，尘埃和齿轮溶解，10¹⁰⁰ 年后只剩一圈微光。
- **深处的视野**：阴影角半径 `sin ψ = (3√3/2)·√(1 − 1/r)/r`。靠近时镜头按 ψ 抬起，始终把阴影边缘留在画面里；越过光子球后阴影超过半个天空，到视界附近，外部宇宙缩成头顶一圈蓝移的光，曝光同时按 γ 补偿。
- **瞬间**（`src/moments.js`）：按坐标时下落，`dr/dt ∝ (1 − 1/r)^1.6`，越近越慢、越红，从外面看永远停在视界上。标签跟随透镜后的像。
- **声音**（`src/audio.js`）：低音随深度打开，指针滴答随外部时钟加快，最后连成嗡鸣；每个瞬间是一声逐渐变低的钟声。全部用 Web Audio 实时合成，默认关闭。
- **后期**：辉光 → 色差、时间静止时的冷色去饱和、ACES、分离色调、暗角、颗粒与白场。

画质分 7 档（像素比 × 光线追踪层分辨率），每 2 秒按平均帧时升降。
