# 作品制作经验

做新作品之前读一遍。每条都来自真实踩过的坑，括号里注明出处，细节见对应作品的 `MAKING.md`。

## 一、立意

1. **先找一个能被看见的规则，再谈美术。** 「时间的尽头」被拆成三个可见的东西：视界上的时间冻结、宇宙的纪元、一座时钟，再用一个机制串起来（越靠近视界，外部时钟越快）。操作本身就是叙事，比堆特效更耐看。（THE END OF TIME）
2. **用真实公式驱动画面。** 光线追踪出的吸积盘「帽子」、多普勒集束、阴影角，转到任何角度都成立；手画的光环只在一个角度成立。夸张可以有，但要在真实值上放大，并在文案里说清楚哪部分是夸张。（THE END OF TIME）
3. **体验要能循环。** 有一个终点，并且终点通向新的开始（越过视界 → 白光 → 下一个宇宙），访客才会玩第二遍。

## 二、画面

4. **物理正确不等于体验正确。** 镜头在 3 rₛ 时阴影角半径已有 45°，对着黑洞只能看到黑。保留物理，改镜头：按阴影角自动抬头，让边缘始终留在画面里。遇到「对但难看」，先改观察方式，不改规则。
5. **密度分布决定是空灵还是雾。** 粒子盘的面密度随半径增大时，整屏会被外圈填成白雾。先算清楚 Σ(r)，再调亮度。
6. **沿光线累加的效果要有门槛。** 光子环辉光沿光线累加，结果被吞没的光线也在发光，阴影变灰。改用守恒量（碰撞参数）直接定位光环。
7. **三维物体要和背景一起变形。** 背景用光线追踪弯曲，前景就在顶点着色器里做同一套透镜，层次才一致。点和线被拉成弧很好看，实心网格会撕裂，宁可隐去。
8. **镜头前的巨物要退让。** 离镜头很近的数字、齿轮又大又清晰，会抢走主体。按距离淡出或缩小，像电影里虚焦的前景。
9. **蓝移、强光要做曝光补偿。** 越深越亮是对的，但要按 γ 补偿曝光，保留变化而不过曝；真正的白场留给结局。

## 三、着色器排错

10. **先二分管线。** 只画背景层；关掉辉光；把片元着色器换成纯红。纯红也看不见，问题在几何或剔除；看得见但颜色不对，问题在着色。
11. **把中间结果画成颜色。** 光线逃逸、被吞没、步数用尽、NaN 各给一种颜色，一张图就能区分「算错了」和「本来就该黑」。
12. **NaN 会经辉光扩散到整屏。** 一个像素的 NaN 进入 UnrealBloom 的模糊链，整帧变黑。常见来源：`pow(负数, y)`（GLSL 未定义，平方请用乘法）、`normalize(0)`、`log(0)`。`smoothstep` 的两个边界不要反着写，要反向请用 `1.0 - smoothstep(a, b, x)`。
13. **屏幕空间扩展的四边形绕序不固定。** 自己在顶点着色器里把线段扩成四边形时，必须 `side: DoubleSide`，否则大约一半（或全部）会被背面剔除。
14. **网格类程序纹理要查邻格。** 星点放在格子里再投影到球面会越界，被格子边界切成方块。用立方体面的二维网格，每个像素检查 3×3 邻格。

## 四、性能

15. **最贵的那一层单独控分辨率。** 光线追踪层渲染到半浮点目标，按 0.5–0.75 倍分辨率再放大；画质档位同时调像素比和这一层的比例，按 2 秒平均帧时升降，降档后 12 秒内不回升，避免来回抖动。
16. **能在着色器里闭式求解的，就不要每帧在 CPU 上算。** 十几万粒尘埃的轨道角有解析积分，CPU 每帧不碰粒子。
17. **远处的光线用解析式收尾。** 碰撞参数足够大的光线不进循环，直接用弱场偏折公式，省掉大部分天空像素的积分。

## 五、验证

18. **没有 GPU 也能看图。** 无头 Chromium 用 SwiftShader 可以渲染 WebGL，但实时循环下截图会超时。给作品加 `?manual`：停掉动画循环，暴露 `advance(秒)` 与 `draw()`，测试脚本逐帧推进再截图；`?q=` 锁定画质档位，保证截图可复现。
19. **每改一处就截一张图。** 序列类效果（下坠、白场、重生）拼成联系表一次看完。截图要看，不要只看脚本退出码。
20. **把公式抽成纯函数模块。** `physics.js` 不碰 DOM 和 WebGL，`node --test` 就能检查时间膨胀、阴影角、纪元边界这类「写错了画面也看不出来」的数字。

## 六、接入图鉴

21. **原型可以野，接入要守规矩。** 原型阶段单文件、CDN、自选字体都行，接入时：使用锁定的 three 版本；界面只用 Atlas 令牌；不用 Google Fonts 和衬线体（画布纹理里的字改用 Geist）；所有文案进 `copy.js` 并有中英文。
22. **封面必须等于初始视角。** 进入过渡会把封面溶进实时画面，所以作品不要再有开场遮罩，打开即是封面那一帧；声音放到按钮里，等访客点。封面用 2880 × 1800 渲染初始视角、隐藏界面后截取，`npm run build` 前会自动生成 AVIF / WebP 和色调。
23. **文风检查会拦感叹号和「震撼」「极致」这类词。** 写完文案先跑 `npm run check`。
