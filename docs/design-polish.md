# 交互与质感规格（顶尖标准）

由 Claude 设计，Codex 按参数实现。参数是设计的一部分：时长、曲线、幅度、触发条件都不要自行调整；觉得不合适，就在 PR 里提出来。

## 一、现在离顶尖还差什么（2026-11-04 自评）

**已经达到的**：
- 版式与字号体系，克制的配色；
- 开窗滚动，跨页过渡（封面无缝变成实时画面）；
- 中英文与无障碍基础；
- 首页不跑 3D 的性能架构。

**还没达到的**（按影响从大到小）：
1. **首页没有动态画面。** 3D 作品集最能打动人的是「动起来的世界」，现在只有静帧。→ 第二节 A
2. **图片清晰度不够。** 封面只有 1440 宽，在 2x 屏和放大的亮点卡上会发虚。→ CODEX-HANDOFF 第 7 项
3. **细节反馈偏少。** 悬停只有放大和环境光，缺少指针光、按压反馈、导航当前位置、图片渐显。→ 第二节 B–F
4. **重复访问时又播一遍入场。** 顶尖网站只在第一次进入时编排入场。→ 第二节 G
5. **没有真机验证。** 过渡、滚动、Safari 和 iOS 的表现都还没确认。→ CODEX-HANDOFF 第 11 项
6. **缺一个只属于 Three Atlas 的标志性交互。** 规划中的「多个世界同处一个空间」就是它，设计稿由 Claude 另出。

## 二、规格

### A. 开窗动态画面（最高优先级）

- **素材**：从作品的**初始视角**录一段 10 秒的真实画面，用 Playwright 注入 CSS 隐藏界面，不改作品源码。要求首尾无缝循环：用 ffmpeg 的 `xfade` 把最后 0.6 秒叠化到开头。
  - 软件渲染太慢、录不流畅的话，请用户在自己的 Mac 上录屏提供原片。
- **编码**：
  - H.264 MP4：`yuv420p`、`crf 23`、`+faststart`；
  - WebM VP9：`crf 34`；
  - 两种尺寸：1920×1200（≤ 4 MB）和 960×600（≤ 1.2 MB，手机和窄屏用）；
  - 文件命名 `public/media/<id>-1920.mp4`，webm 和 960 同理。works.json 新增可选字段 `"preview": "media/<id>"`。
- **行为**：
  - 在 `FeatureWindow` 的封面上方叠一个 `<video muted playsinline loop preload="none" poster="封面">`。
  - 窗口进入视口、页面可见时才加载和播放；离开视口或切到后台就暂停。
  - 收到 `playing` 事件后用 600ms（`--e-std`）淡入，之前一直显示静帧。
  - 开启「减少动态效果」、`Save-Data`，或者网络是 2G/3G 时，不加载视频。
- **跨页过渡**：视频正在播放时，`pageswap` 给 video 设 `view-transition-name`；否则沿用静帧。
- **验收**：首屏 LCP 仍然是封面图，视频不能拖慢 LCP；滚动到窗口后 1 秒内开始播放；循环接缝看不出来。

### B. 指针光（卡片与亮点卡）

- 只在 `(hover: hover) and (pointer: fine)` 的设备上启用。
- `.ui-card__picture` 和 `.ui-panel` 上加一层 `::before` 覆盖层：`radial-gradient(360px circle at var(--mx) var(--my), rgb(255 255 255 / 0.09), transparent 62%)`。
- 同时把 1px 描边改成随指针变亮：用 mask 实现，指针附近的描边为 `rgb(255 255 255 / 0.28)`，其余部分保持 `--c-line`。
- 指针进入时光层在 300ms 内淡入，离开时 500ms 淡出。坐标只在 `pointerenter` 时读一次 `getBoundingClientRect`，`pointermove` 里用 rAF 更新 `--mx`/`--my`，不触发布局。
- 同一时间只有一张卡亮。

### C. 开窗的指针视差

- 窗口内的封面或视频跟随指针平移，最大 ±1.2%（相对尺寸）。
- 每帧以 `lerp 0.08` 缓动追随；指针离开后回到中心。
- 粗指针设备和「减少动态效果」时关闭。

### D. 图片渐显

- 组件内所有图片初始 `opacity: 0`，`decode()` 完成后用 600ms（`--e-std`）淡入。不能出现「先空白、再突然出现」。
- 占位底色用封面的平均色：构建时计算，写入 works.json 可选字段 `"tone": "#1a1630"`，由脚本自动生成，不要手填。

### E. 导航当前位置

- `GlobalNav` 的链接根据当前所在区块设置 `aria-current="true"`。以视口中线为准，用 ScrollTrigger 实现。
- 视觉：当前项文字为 `--c-fg`，下方居中一个 4px 圆点。圆点在链接之间移动时用 400ms（`--e-out`）滑动过去。

### F. 按压反馈

- `.ui-btn:active`、`.ui-chip:active`、`.ui-gallery__paddle:active`：`transform: scale(0.97)`，120ms。松开时 240ms（`--e-out`）回弹。

### G. 入场只在第一次

- 首页入场编排（标题逐行升起、导语和窗口淡入）在同一会话内只播放一次，用 `sessionStorage` 记录。
- 从作品页返回、刷新、切换语言时都直接显示，不再播放。

### H. 页脚字标

- 页脚进入视口时，大字标「Three Atlas」逐字母升起：SplitText chars，`yPercent 60 → 0`，1.2s `expo.out`，每字错开 0.03s，只播一次。

### I. 性能与质量预算（顶尖的硬指标）

以中端手机、Fast 4G 为准：
- LCP ≤ 2.0s，CLS ≤ 0.02，INP ≤ 100ms；
- 首页 JS ≤ 70 KB gzip（目前约 61 KB）；
- Lighthouse 的性能、无障碍、最佳实践、SEO 四项都 ≥ 95。

新增 `npm run perf`（Lighthouse CI），不达标时失败。

### J. 无障碍复核

- 全站对比度达到 WCAG AA。`--c-fg-4` 只能用于纯装饰，例如「关于」里的大编号。
- 键盘走一遍完整流程：跳到作品 → 搜索 → 卡片 → 进入作品 → 返回。焦点必须始终可见、顺序合理。

## 三、设计验收

每项完成后，在 PR 里附上：
- 改动前后截图（桌面 1440×900、手机 390×844，中英文）；
- 涉及动效的，附一段 5–10 秒的录屏（Playwright `recordVideo` 即可）。

由 Claude 做审美验收，通过后再合并。
