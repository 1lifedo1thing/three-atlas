# Three Atlas 首页设计说明（Opus 5.5，2026-11-04）

目标：简单、简约、大气，作品画面优先。首页不加载 Three.js，只用封面图和轻量交互。整个站点围绕一个比喻：**每张封面都是一扇窗，走进去就是另一个世界。**

## 版式

1. **开场**：居中的大标题「世界之中 / 另有世界」（英文 *A world of worlds.*），配一句说明。除此以外没有任何装饰。
2. **开窗**：目录中第一个作品以圆角窗口的形式出现在首屏下沿。向下滚动时窗口逐渐扩展到满屏，同时出现作品名和「进入体验」按钮。这是整个首页唯一的动效段落。
3. **全部作品**：搜索框加卡片网格。只有一个作品时卡片横向排列，图在左、文在右；有多个作品时自动变为网格。不放虚构作品或占位卡片。
4. **收尾**：一句「更多世界，正在路上」，署名，以及一个大号的 Three Atlas 字标。

## 视觉

- 中性近黑色底 `#070708`，暖白色文字 `#f5f4f2`。平台本身没有主题色，颜色全部来自作品封面。
- **环境光**：窗口和卡片背后各有一张模糊、放大的封面副本，把作品自己的颜色洒到页面上，所以紫色作品透紫光，以后其他颜色的作品也各显其色。实现方式是给一张小图做模糊再放大，开销很低。
- 字体：拉丁文用 Geist Variable（自托管），中文用系统黑体（PingFang、HarmonyOS、Noto Sans SC、雅黑）。不依赖 Google Fonts，保证中国大陆可以访问。
- 统一的圆角、胶囊按钮和发丝线，不使用玻璃面板，不使用粒子背景。

## 进入与返回

使用浏览器原生的跨文档 View Transitions，没有共享渲染器，每个作品仍然是独立页面：

- **首页 → 作品**：点击的封面放大成满屏静帧（`.atlas-arrival`）。作品就绪（`body.ready`）后，静帧在 1.4 秒内淡出，露出实时画面。因为封面就是从作品初始视角截取的，两者能对齐。
- **作品 → 首页**：作品画布收回到它在首页的那张封面上。
- 不支持的浏览器（目前是 Firefox）、直接打开作品链接、开启「减少动态效果」时，一律按普通页面跳转，作品页的表现和原来完全一样。
