# Three Atlas 首页设计说明（Opus 5.5 · 第四版）

规则与组件见 `docs/design-system.md`。本文只记录设计理由。

## 这一版改了什么

用户希望网站**有文化、有技术、有底蕴，说话如沐春风**。所以把第三版里 Apple 式的「近看这个世界」换成了中国画论的框架，同时保留顶尖产品页的版式标准：作品为主、一屏一事、动效有叙事意义。

## 首页叙事

1. **咫尺之间，自有天地。** 开场。化用山水画「咫尺千里」的传统：方寸屏幕里，自有一方天地。
2. **开窗**：主推作品的窗口随滚动展开为满屏（沿用第三版）。
3. **卧游**：宗炳「澄怀观道，卧以游之」。先讲一千五百多年前的卧游，再说三维图鉴就是今天的卧游。今释文字随阅读逐词点亮。
4. **可行，可望，可游，可居。** 郭熙论山水的四种境界，对应作品的四种体验：
   - 行：轨道相机、阻尼缓动、键盘可达
   - 望：13,500 片实例化树叶、实时辉光
   - 游：光芒滑块
   - 居：Web Audio 合成的宫、徵两音，加程序化云层

   形式是**四条屏**：画心在上，题跋在下，中文题跋竖排、从右往左。
5. **以代码为笔，以光为墨。** 笔（程序生成，无外部贴图、模型和录音）、墨（Three.js 实时渲染与辉光）、纸（浏览器，无需下载、无需登录）。
6. **全部作品**，以及收尾句「此卷未完，世界还在生长。」

以上每一个技术说法，都已在 `experiences/where-stars-rest/src/` 中核对过。

## 对齐对象

版式与动效继续对齐 Apple 产品页、Linear 和 threejs.org（调研见第三版提交记录）。文化表达参照博物馆的展陈语言：先给原文与出处，再给一段平实的今释。
