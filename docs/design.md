# Three Atlas 首页设计说明（Opus 5.5 · 第三版）

规则与组件见 `docs/design-system.md`。本文只记录为什么这样设计。

## 对齐对象与借鉴点

2026-11-04 实际访问并截图了以下网站，按共同规律提炼：

| 参考 | 借鉴 |
| --- | --- |
| Apple 产品页（Vision Pro） | 全屏主图，作品名放左下、两个按钮放右下；大段宣言随滚动逐渐点亮；「近看」横向大图集，配圆点和左右翻页按钮；滚过主图后出现作品名加购买按钮的局部导航（这里对应导航栏里的「进入体验」）。 |
| Linear | 克制的深色、精确的网格；两种明暗的文字形成主次（主句亮、补充暗）；等宽字体的小标签。 |
| threejs.org | 作品墙：作品本身就是界面，平台的存在感降到最低。 |
| 腾讯混元 3D、Tripo | 3D 内容平台的信息组织方式。但它们以工具和登录为中心，我们不需要。 |

## 首页叙事

1. **开场**：「世界之中，另有世界。」主推作品的窗口已经出现在首屏里。
2. **开窗**：滚动时窗口固定在屏幕上并展开到满屏，然后出现作品名和「进入体验 / 了解更多」。
3. **宣言**：说清楚这是什么——观默创作的交互式三维世界，无需下载、无需登录。
4. **近看**：用主推作品的真实画面细节和真实功能（环绕、同步呼吸、光芒调节、云层、氛围音）说明它好在哪里。
5. **目录**：全部作品，可以搜索、筛选。
6. **收尾**：「更多世界，正在路上。」加上链接分栏和大字标。

## 主推作品

由 `content/works.json` 中的 `"featured": true` 手动指定，按用户要求。当前是 WHERE STARS REST。
