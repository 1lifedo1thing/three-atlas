# WHERE STARS REST

星光的归处。一处悬浮于星海的微小庇护所。

从 Three Atlas 根目录执行 `npm ci` 与 `npm run dev`，打开 `/experiences/where-stars-rest/index.html`。本目录是独立网页入口，与首页共享构建工具和依赖，不共享运行中的场景或样式。

## 交互

- 拖动 / 单指拖动：环绕岛屿；滚轮 / 双指：缩放。
- 光芒滑杆：调整 0–100% 光晕与局部照明，默认 55%，在当前站点保存偏好。
- 点击树冠：触发光与粒子的回应。
- 右下按钮：暂停 / 继续自动旋转，或回到初始构图。
- 右上声音按钮：手动启用本地合成氛围音，默认关闭。
- 聚焦画布后使用方向键、`+` / `-`、`Home` 与空格探索。
- 右上返回链接：回到 Three Atlas 图鉴。

需要 WebGL 2。系统启用「减少动态效果」时停止自动漂浮与呼吸动画；标签页隐藏时暂停渲染和声音。

## 内容与保留范围

地形、岩体、树木、草叶、晶簇、菌菇、萤火、云与材质纹理均由程序生成。没有使用外部模型、图片贴图、字体或音频。源模块与测试按作者当前版本导入，本次只在 HTML 加入返回图鉴的链接和共享导航样式。
