# THE END OF TIME / 时间的尽头 · SOL

**本版由 Codex 6.1 sol 制作。** 图鉴中前一件同名作品由 **Claude Code opus5.5** 制作，保存在 [end-of-time](../end-of-time/README.md)。这是两件独立实现，不覆盖彼此。

一座破碎的天文钟悬在黑色潮汐上。环绕奇点，在星尘与水面倒影之间，拾回三个属于人类的瞬间。

- 入口：`/experiences/end-of-time-sol/index.html`。
- 拖动环绕、滚轮靠近；原地长按积蓄引力，松开释放时空涟漪。
- 双击发光的菱形晶体收集记忆，收集三枚后出现结语。
- 时间控制条支持暂停、倒流、向前及 0.25–2.00 倍流速。
- Space 暂停或继续，R 切换时间方向，H 隐藏界面，Esc 恢复界面或关闭面板，1 / 2 / 3 切换视角。
- 声音默认关闭，点击后启动 Web Audio 合成的环境声。刷新会重新开始记忆收集。
- 支持中英文、手机布局与减少动态效果；顶部返回图鉴。

## 实现

立体金属钟环、刻度、罗马数字与漂浮碎片构成天文遗迹。暗核由球体与 Fresnel 光环构成，吸积盘和星尘使用 GLSL 着色器；它是艺术化的宇宙场景，没有采用前一版的度规光线积分。

桌面 34,000 枚轨道星尘，手机初始使用 19,000 枚。实时平面反射叠加波面扰动，倒映遗迹与星光；HDR 后期包含辉光、色调映射和引力脉冲折射。所有持续运动共用可暂停、可倒流的模拟时钟。声音由 Web Audio 实时生成，字体为本地字形子集。

接入 Three Atlas 时沿用仓库固定的 Three.js 0.186.1 与 Vite 8.3.5，保留原场景的构图、材质和交互。仅加入相对路径、返回导航、双语与页面就绪状态。

运行与构建使用仓库根目录的命令。验证记录见 [接入说明](../../docs/end-of-time-sol.md)。第三方来源与许可证见 [THIRD_PARTY.md](./THIRD_PARTY.md)。
