# Three Atlas 首页设计说明（Opus 5.5 · 第六版）

规则与组件见 `docs/design-system.md`，交互参数见 `docs/design-polish.md`。

## 这一版改了什么

用户的意见：网站没必要搞得复杂。进来就应该看到很多卡片，点进去就能看；长篇的叙事会让人不愿意往下拉，我们本质上是作品集，不是产品官网。

所以首页改成**画廊优先**，参照 threejs.org 的作品墙和 Awesome AI Motion 的卡片浏览：

1. **标题区只占一点地方**：「可以走进去的三维世界。」加一句说明，约占首屏的四分之一。
2. **吸顶工具条**：作品数量、类别筛选（两类以上才出现）、搜索（按 `/` 聚焦）。滚动时一直在顶上，作品多了也好找。
3. **作品网格**：主推作品排在最前、最大，画面上叠着标题和「进入」，并且会自动播放动态预览；其余卡片三列排开，只写标题、类别和一句副标题。只有一件作品时，主推卡正好填满首屏剩下的空间。
4. **关于图鉴**：作品之后放一条很短的四句话（独立运行、组件复用、轻快打开、接下来）。
5. **页脚**不变。

去掉了开窗滚动、宣言、亮点卡和长篇「关于」。这些组件保留在组件库里，以后做作品详情页时可以用。
