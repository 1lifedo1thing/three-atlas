# 幽珊 / Lumen Corallum

悬浮的幻想生物，融合半透明水母瓣膜、珊瑚分枝骨架和种核。圆润触腕与细触须缓慢舒展，体内外光点与形体同步呼吸。

- 入口：`/experiences/lumen-corallum/index.html`，左上角返回 Three Atlas。
- 中英文与图鉴共用语言偏好，刷新后保留。
- 拖动旋转、滚动或双指缩放、轻点唤光；四个视角分别观察整体、骨架、种核和触须。
- 空格暂停或继续，H 隐藏或显示界面，1–4 切换视角；画布获得焦点后可用 Shift + 方向键旋转。
- 系统开启减少动态效果时默认暂停；可主动继续。
- 造型、纹理、粒子和动态均由程序生成，无外部模型或贴图。来源与许可见 `THIRD_PARTY.md`。

测试：在仓库根目录运行 `npm test`，包含几何、触腕截面、呼吸、粒子和双语覆盖检查。
